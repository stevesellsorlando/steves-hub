# Steve's Hub

Steve's private real estate hub: Clients, Probates, Expireds, follow-ups and more.

- **Built with:** Next.js, TypeScript, Tailwind, Supabase (database, sign-in), hosted on Vercel.
- **Database setup:** run the files in `supabase/` in order, in the Supabase SQL Editor for the project named **steves-hub**.
- **Secret keys** live in Vercel's settings (Settings > Environment Variables), never in this code. See `.env.example` for the names.
- **Plan and progress notes:** `docs/STEVES-HUB-PLAN.md` and `docs/WHERE-WE-ARE.md`.
